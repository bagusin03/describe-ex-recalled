One word, 8 characters — my ex, summed up as a faulty product pulled off the shelves:

> Recalled

`main.ts` writes the single word to `/output/entry.txt`.

Offline and deterministic: no network, no clock, no randomness. A runtime guard enforces the 1–111 character gate and verifies the written file round-trips exactly.

Run it with Node 22+:

```
node main.ts
```
